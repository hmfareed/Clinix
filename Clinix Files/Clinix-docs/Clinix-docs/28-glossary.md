# 28 — Glossary (new)

| Term | Meaning |
|---|---|
| Triage | Sorting patients by how urgently they need care |
| Urgency floor | The minimum urgency a rule enforces; the AI cannot go below it |
| Differential | A list of plausible explanations for symptoms, not a diagnosis |
| Tri-state | A field that is `yes`, `no` or `unknown`; unknown is never treated as no |
| Safety gate | Post-generation check that re-applies rules to the AI's output |
| Kill switch | Feature flag that disables a model, rule set or module quickly |
| Golden case | A clinician-reviewed test scenario with an expected minimum urgency |
| RBAC | Role-based access control |
| Break-glass | Time-limited, justified, audited access to sensitive data |
| TTL index | MongoDB index that expires documents automatically |
| NIM | NVIDIA Inference Microservices; OpenAI-compatible hosted inference |
| Act 843 | Ghana's Data Protection Act, 2012 |
| DPC | Ghana's Data Protection Commission |
| NAS | National Ambulance Service (Ghana) |
| False negative | A missed emergency; the most serious failure type here |
| Over-triage | Rating a case more urgent than needed; tolerated more than under-triage |
