# 09 — Ambulance and Emergency Calling

Emergency handling must be **independent of the general chatbot**.

## Ghana baseline

The Ghana National Ambulance Service identifies **112** as its emergency number and states assistance is available 24/7 nationwide. Verify the number and its operational status before each deployment, and configure emergency numbers **per country** rather than hardcoding Ghana.

## Emergency screen

```
You may need emergency medical assistance
If you are experiencing severe or life-threatening symptoms,
do not wait for the AI assessment to finish.

Ghana emergency ambulance number
            112
Confirm your country if you are outside Ghana.
        [ Call emergency services ]
```

The button opens the device's calling interface (`tel:112`). It does **not** dispatch an ambulance or verify a call connected.

## Functionality

- Prominent emergency call button when necessary
- Country-aware numbers from verified configuration (`emergencyConfigurations`)
- Immediate emergency instructions from approved guidance
- Optional facility search as a secondary action
- Fallback that displays the number if the device cannot place calls
- Optional trusted-contact notification, only with consent and a defined delivery mechanism
- Optional location sharing with explicit consent and clear explanation
- A record of the emergency action *initiated*, without falsely recording that an ambulance was dispatched

## Dispatch boundary

Opening a phone call is **not** dispatching an ambulance. A real dispatch integration needs an authorized arrangement with the ambulance service, infrastructure and operational procedures. Do not advertise automatic dispatch until it is implemented and tested. Treat it as a separate operational project.

## Reliability requirements (new)

- `/emergency` is statically rendered and works without database, AI or maps.
- Emergency numbers are bundled as a build-time fallback JSON in case the config API fails.
- The emergency call button appears in the global header on every page.
- Emergency instructions content is stored as reviewed static content, not generated by the model.
- Audit event `emergency_action_initiated` records action type and timestamp only, never the transcript.
